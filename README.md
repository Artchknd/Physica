# Interactive 3D Physics Lab

Real-time 3D physics laboratory in the browser: mechanics (Rapier), optics, waves,
electromagnetism and thermodynamics. Built with Next.js, Three.js and Chart.js.
Fully client-side; scenes are saved to localStorage. UI languages: zh-TW / English.

## Develop

    npm install
    npm run dev

## Build

    npm run build
    npm start

No environment variables or database are required.
